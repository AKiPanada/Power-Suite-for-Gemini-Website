# Power Suite for-Gemini Website
This is the public-facing site for my Power Suite for Gemini extension on Chrome.

# Privacy
Power Suite for Gemini does not collect, store, transmit, or sell any personal data. It runs entirely in your browser on gemini.google.com. The only data it stores is your extension settings (on/off, minimap preview lines, swap-Enter, and light/dark theme), saved locally using Chrome’s storage API. It does not use analytics, tracking, or remote servers.
